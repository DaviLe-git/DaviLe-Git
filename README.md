# About

I'm an **Analysis and Systems Development** student from Brazil focused on **Offensive Security**.

Most of my learning comes from solving CTFs, reading source code, building vulnerable environments and understanding why applications fail.

Instead of collecting tools, I prefer understanding the internals behind vulnerabilities:

- authentication mechanisms
- backend logic
- insecure design
- Active Directory
- privilege escalation
- web exploitation

I believe good pentesting starts long before the exploit.

It starts by understanding the application.

# Methodology

Most challenges follow approximately the same workflow.

```
Recon
      ↓
Enumeration
      ↓
Understanding the Application
      ↓
Threat Modeling
      ↓
Exploit Development
      ↓
Privilege Escalation
      ↓
Documentation
```

The exploit is usually the shortest part.

Understanding why it works is the interesting one.
